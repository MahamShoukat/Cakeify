# Cakeify
Cakeify is a UI/UX design project for a custom cake ordering mobile app.

### Features
- Step-by-step cake customization
- Skip option for toppings and extras
- Suggestion box at each step
- Live price update
- Order placed 2 days in advance

### Tool
- Figma
### Role
- UI-UX Designer (Beginner)
